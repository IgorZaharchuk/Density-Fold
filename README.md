Density Fold

Настройка плотности интерфейса (DPI) и автоматическое переключение параметров экрана на Samsung Galaxy Z Fold.

Density Fold позволяет задать отдельную плотность интерфейса для внутреннего и внешнего экранов складного устройства. Приложение применяет настройки вручную или автоматически при складывании и раскрытии устройства.

Для изменения системной плотности используется "Shizuku" (https://shizuku.rikka.app/) — приложение не требует постоянного подключения к компьютеру после запуска Shizuku.

«Статус проекта: beta. Основная целевая платформа — Samsung Galaxy Z Fold. Работа на других складных устройствах не гарантируется.»

Возможности

- Отдельные настройки DPI. Независимые значения для внутреннего и внешнего экранов.
- Ручное применение. Изменение DPI непосредственно из приложения.
- Автоматическое переключение. Применение соответствующего значения при складывании или раскрытии устройства.
- Быстрые действия. Команды «Внутренний» и «Внешний» доступны через ярлыки приложения.
- Мониторинг в фоне. Сервис отслеживает состояние экрана и отображает текущий статус в уведомлении.
- Восстановление связи с Shizuku. Приложение отслеживает состояние подключения и предпринимает попытки восстановить работу после потери Binder.
- Автозапуск. Возможность включить запуск мониторинга после перезагрузки устройства.

Требования

- Android 8.0 или новее.
- Складное устройство с внутренним и внешним экранами.
- Установленное и запущенное приложение "Shizuku" (https://shizuku.rikka.app/).
- Разрешение Shizuku для Density Fold.
- Разрешение на фоновый запуск для механизма восстановления Shizuku.

Для автоматической работы также рекомендуется разрешить уведомления и не ограничивать фоновую работу приложения средствами энергосбережения прошивки.

Установка и настройка

1. Установите Shizuku

Установите Shizuku и запустите его одним из поддерживаемых способов:

- через беспроводную отладку;
- через root-доступ.

Инструкции по запуску доступны в "официальном руководстве Shizuku" (https://shizuku.rikka.app/guide/setup/).

2. Установите Density Fold

Установите APK приложения и откройте его.

3. Предоставьте разрешение Shizuku

В Shizuku найдите Density Fold в списке приложений и предоставьте ему разрешение.

Вернитесь в Density Fold и убедитесь, что соединение с Shizuku отображается как активное.

4. Разрешите фоновое восстановление

Предоставьте Density Fold разрешение «Поверх других приложений».

Оно используется для восстановления подключения к Shizuku в ситуациях, когда Android ограничивает запуск фоновой активности.

5. Настройте DPI

На главном экране доступны две независимые настройки:

- Внутренний экран — значение DPI для раскрытого устройства.
- Внешний экран — значение DPI для сложенного устройства.

Выберите нужные значения и нажмите «Применить» в соответствующем блоке.

6. Включите автоматизацию

В разделе «Автоматизация» доступны два переключателя:

- Автоприменение при складывании — автоматически менять DPI при смене экрана.
- Автозапуск при загрузке — запускать мониторинг после перезагрузки устройства.

Быстрые действия

Density Fold добавляет два ярлыка приложения:

- Внутренний — применить настройки внутреннего экрана.
- Внешний — применить настройки внешнего экрана.

Чтобы воспользоваться ими, нажмите и удерживайте значок Density Fold на рабочем столе и выберите нужное действие.

Ярлыки позволяют переключить DPI без открытия главного окна приложения.

Как работает автоматизация

Когда автоматизация включена, Density Fold запускает фоновый сервис мониторинга.

Сервис отслеживает смену активного экрана и определяет, какие настройки DPI необходимо применить. При необходимости он запускает соответствующее действие.

Результат отображается в системном уведомлении.

Если связь с Shizuku временно потеряна, приложение отслеживает состояние подключения и пытается восстановить работу. Успешное восстановление зависит также от настроек Android, состояния Shizuku и ограничений фоновой активности производителя устройства.

Устранение неполадок

Density Fold показывает, что Shizuku недоступен

1. Откройте Shizuku и проверьте, запущена ли служба.
2. Проверьте, предоставлено ли Density Fold разрешение.
3. При необходимости перезапустите Shizuku.
4. Вернитесь в Density Fold и проверьте подключение.

Автоматическое переключение не работает

1. Убедитесь, что включено «Автоприменение при складывании».
2. Проверьте, что Shizuku запущен и разрешение предоставлено.
3. Убедитесь, что мониторинг отображается в уведомлениях.
4. Проверьте разрешения фоновой работы и энергосбережения Android.

DPI не изменяется

Проверьте подключение Shizuku и повторите ручное применение нужного значения. Если проблема сохраняется, перезапустите Shizuku и проверьте результат ещё раз.

Сборка из исходного кода

Проект использует Gradle, Kotlin, Android SDK 34 и JDK 17.

Для сборки debug APK:

git clone https://github.com/IgorZaharchuk/Density-Fold.git
cd Density-Fold

chmod +x gradlew
./gradlew :app:assembleDebug

Готовый APK:

app/build/outputs/apk/debug/app-debug.apk

Сборка через GitHub Actions

Проект автоматически собирается при отправке изменений в репозиторий. Также сборку можно запустить вручную через "workflow_dispatch".

Готовый APK публикуется как артефакт GitHub Actions. Срок хранения артефакта — 30 дней.

"Открыть сборки GitHub Actions" (https://github.com/IgorZaharchuk/Density-Fold/actions)
